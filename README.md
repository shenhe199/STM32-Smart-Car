## STM32 双轮差速智能小车（高精度闭环控制）开发报告

## 一、开发环境搭建
* 安装keil并破解，安装stm32cub，下载stlink驱动和ch340串口驱动以及xcom串口助手
* 下载标准库和hal库文件

## 二、pc13闪灯，串口模拟呼吸灯
* 学会使用cub来配置引脚
* 用delay（）；达到pc13led闪灯的效果
* 呼吸灯原理是通过设置占空比的大小控制led亮度，没有现成led于是通过串口输出占空比大小来观测占空比变化
* 遇到芯片锁死，下载STM32CubeProgrammer，强制擦除，并且配置sys杜绝锁死情况

## 三、i2c通信协议，配置mpu6050和oled
* 使用硬件 I2C一直报读取不到陀螺仪数据，网上了解到单片机硬件i2c存在硬件缺陷。最后果断放弃硬件 I2C，把引脚换到 PB14/PB15，使用ai生成软件模拟i2c的库文件以及mpu6050的库文件，彻底绕开底层死锁
* oled使用相同引脚，并ai生成oled库文件
* 学习微元法积分，因为主循环里有 OLED 刷屏，导致实际循环时间不准，转 360 度误差极大，于是用固定的时间系数去乘角速度进行微元法积分，使mpu6050大致准确
* 改为使用 HAL_GetTick() 获取真实时间差进行动态积分，彻底消灭了时间误差，并且加入了微动死区

## 四、电机与编码器
* 使用编码器控制直行距离，并且加入梯形速度控制（直行和转弯）防止空转和惯性过大
* 加入编码器时失误接线，导致短路，驱动无法给单片机，被迫双电源供电

## 五、算法优化，代码优化与调试参数
* 为了克服左轮功率偏低的硬件差异，原本使用固定量补偿，后面感觉固定值难以保证其不偏航，加入基于陀螺仪偏航角的动态死区纠偏，配有死区
* 有的时候直行结束时依然有偏航，原因是发现偏航时直行已接近尾声，来不及纠正，于是加入航向二次对齐，配有死区
* 由于物理惯性，转弯的角度不够稳定，所以加入停车后航向对齐，且配有死区
* 所有功能加入后，因为许多ai生成的代码拼接在一起，缺乏条理性，臃肿，我对代码进行重整优化，加注释，优化结构，封装函数，并新建了一个库文件用于存放函数，简化main文件，基本所有参数使用宏定义放置于main.h
* 经过数十次的实测，标定了 84° 动力断电提前量、58.5cm 的直行目标以及双死区范围，航向对齐最小占空比等核心参数
