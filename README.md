## 📖 项目简介
本项目是一个基于 **STM32F103C8T6** 的双轮差速智能小车。项目从零手搓底层驱动到上层控制算法，实现了高精度的定距与定角功能，小车能够自主巡航完美的正方形轨迹。

---

## ✨ 核心功能与硬核亮点

### 1. 底层通信：AI辅助手写软件模拟 I2C
*   **痛点**：STM32F103 硬件 I2C 极易发生死锁。
*   **解决方案**：将 GPIO 配置为**开漏输出（Open-Drain）+ 内部上拉**，AI辅助手写 `Start`、`Stop`、`SendByte`、`ReadByte` 时序，彻底根除硬件死锁风险。
*   **防御性设计**：实现 `IIC_BusRecover()` 机制。当总线意外卡死时，通过发送 9 个时钟脉冲强行冲刷从机状态机，并发送 STOP 信号复位总线。
*   **读写方向切换**：严格遵循 I2C 协议，在读取 MPU6050 前，通过 `Restart` 信号重新寻址，实现从写模式到读模式的无缝切换。

### 2. 感知层：MPU6050 姿态解算
*   采用 **MPU6050_Read_All()** 一次性读取 14 个字节的加速度与角速度原始数据，避免分次读取带来的时间差。
*   严格处理 C 语言数据类型转换，通过强制转换安全拼接高低位，防止补码解析错误。
*   **微元法动态积分**：利用 `HAL_GetTick()` 获取动态时间戳，计算微秒级时间差 `dt`，将陀螺仪角速度进行积分，实现高精度的航向角解算。

### 3. 控制层：闭环控制与多级纠偏
*   **梯形加减速**：基于编码器反馈的脉冲数，设计梯形加减速曲线，有效抑制起步打滑与刹车过冲现象。
*   **双死区 PID 纠偏**：针对直线行驶和原地转向，设计了不同的 PID 参数与死区阈值，减少因电机硬件差异带来的航向偏移。
*   **二次航向对齐**：在转弯结束时，引入二次绝对航向对齐机制，消除因惯性带来的航向偏离。

## 🛠️ 硬件架构
| 模块 | 型号 | 通信/控制接口 |
| :--- | :--- | :--- |
| **主控芯片** | STM32F103C8T6 | - |
| **姿态传感器** | MPU6050 (六轴) | 软件模拟 I2C |
| **显示模块** | 0.96寸 OLED | 软件模拟 I2C |
| **电机驱动** | TB6612FNG | GPIO + PWM |
| **电机** | 带霍尔编码器减速电机 | 定时器编码器模式 (Encoder Mode) |
